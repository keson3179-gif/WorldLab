# V4 Phase 19｜決策

V4.1 的研究架構改為五層證據，P4 拆成 P4a 與 P4b。Phase 17 對原三群 M0+X 仍是 NO-GO。Phase 18 對原九處獨立歷史網路關注仍是 NO-GO。這兩項沒有改寫。

P4b 現在不能執行。公布時間不可重建，場所身分沒有建立，也還沒有外部時間戳記。P4a 的比較規則已經寫死，但本輪沒有計算。不能用 P4a 宣稱預測成功。

ProspectiveRegistry 已改為凍結後不可原地修改、修訂使用新識別碼、保存預測與程式位元組、使用帶時區的 UTC 時間，並把首次觀察與後續修訂分開。本地檔案只是 API 層的追加紀錄，不是不可竄改儲存。測試使用合成資料。

三年工作改為輸入穩健性、資料識別、封存基礎設施、模型內機制，以及有條件的外部檢查。真人問卷不是必要項目，也不承諾樣本數。問卷經費若要改列，必須經過計畫的合法變更程序，不能因本輪結論直接挪用。

本輪沒有執行正式 P4，沒有大規模 LLM 呼叫，沒有大規模 ABM，沒有新的參數搜尋，也沒有修改 V4 Word。Experiment 021 尚未開始。

正式 V4.1 文字應等到這份架構與封存測試被接受之後，再按 `V4_PHASE19_V41_REVISION_MAP.md` 修稿。
