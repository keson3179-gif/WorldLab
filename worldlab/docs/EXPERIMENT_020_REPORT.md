## 回答

這輪識別的是來源與時間安排的干預效果。兩種 field 的分布與實際 Q 不同，所以下面的差不是等 Q 的純 feedback，也不是機制貢獻百分比。外生 field 只替換決策用的 social score；recipient 的 occupancy、移動與 Atlas base utility 仍依自身狀態更新。連續 20 步達到 18/20 不是永久吸收態。未發生的事件留在分母裡，沒有被記成第 500 步。

早期來源會改變強集中的形成，而且只出現在高權重 LOGMAX。E-early 與 O-early 各算一次。O-early 在 18 個條件都是 0/1000。E-early 的 18/20 事件：CUM LOGMAX q15 為 980/1000，風險差 0.980 [0.971, 0.988]；q25 為 1000/1000，風險差 1。EXP99 q15 為 942/1000，差 0.942 [0.927, 0.956]；q25 為 1000/1000。RW50 q15 為 786/1000，差 0.786 [0.761, 0.811]；q25 為 998/1000，差 0.998 [0.995, 1.000]。這些 q25 事件的起始中位數是 committed t=4，確認中位數是 t=23。q15 的起始中位數是 t=5 或 t=6。q05 的三個 LOGMAX，以及全部 ZRAW，E-early 與 O-early 都是 0/1000，風險差的區間是 [0, 0]。

後期來源會改變已經形成的集中是否維持，但只能在 E-early 這個事前資格層估計。資格是 commits t=31–50 同一場所至少 18 人，分母由切換前決定。LOGMAX q25 的合格數是 CUM 1000、EXP99 1000、RW50 998。EE 把原場所維持到 t=500 的比例是 1，沒有人在視野內跌破 18 人。EO 的維持比例是 0，解除比例是 1，場所轉移比例是 0。六個 LOGMAX q15/q25 的 EO 條件裡，original_exit 與 release_time 的次數分布相同：每個條件都是 t=51 比合格數少 1，另有 1 個 seed 在 t=52。因此所有合格世界都在 t=51–52 解除集中，退出時間的中位數為 t=51。維持差 EE−EO 在 q25 是 1.000 [1.000, 1.000]。q15 的合格數是 CUM 979、EXP99 942、RW50 782。EE 的維持比例是 1、0.9989、0.9974；EO 的維持比例仍是 0，解除比例是 1，轉移比例是 0，退出中位數同樣是 t=51。配對維持差的區間下緣都高於 0.993。O-early 的合格數在 18 個條件都是 0。條件式維持是 NA，bootstrap 的 10000 次重抽都因空分母被捨棄，沒有被填成維持率 0。

早期使用 O、後期恢復 E，在 LOGMAX q25 仍會形成強集中，但形成得比較晚，而且不是每一個 memory 的 q15 都會補上。OE 的晚期新事件：CUM q25 為 984/1000，16 個未發生，起始中位數 t=69；EXP99 q25 為 999/1000，起始中位數 t=75；RW50 q25 為 1000/1000，起始中位數 t=92。這三條的 t=101–500 HHI 是 0.975、0.985、0.984，EE 則是 1。q15 的晚期新事件是 CUM 184/1000、EXP99 435/1000、RW50 826/1000，起始中位數分別是 t=199.5、t=301、t=343.5，晚期 HHI 是 0.582、0.641、0.668。OO 在全部條件的晚期新事件都是 0。晚期有集中的 OE 種子，切換前都還沒有完成早期形成。

效果依 transformation 與 q 標籤明顯不同，也依 memory 改變大小。LOGMAX q25 的晚期來源對照 EE−EO 約 0.767–0.773，OE−OO 約 0.741–0.757。q15 的 EE−OE 是 0.313–0.413，EE−EO 約 0.768–0.781，OE−OO 是 0.367–0.455。q05 的 HHI 差只有約 0.004–0.064，而且沒有 18/20 事件。全部 ZRAW 都沒有 18/20 事件；晚期 HHI 對照最大約 0.014。晚期固定為 O 的 early_given_O（EO−OO）共 18 格，平均差的絕對值都在 1.4×10⁻⁵ 以內。其中 17 格的 95% 區間包含 0。EXP99 ZRAW q25 的平均差是 1.3206593749999967×10⁻⁵，區間是 [2.0166250000004103×10⁻⁶, 2.4608343750000926×10⁻⁵]，完全高於 0。本輪沒有等價判準，接近零或區間含零都不是已證明沒有差異。EO 與 OO 的軌跡 hash 仍然可以不同。實際 Q 也沒有被配成相等。以 CUM LOGMAX q25 為例，t=1–50 的 Q_used 在 EE 是 0.933、在 OE 是 0.445；t=51–100 在 EO 降到 0.296、在 OE 升到 0.868；t=101–500 則是 EE 0.957、EO 0.228、OE 0.954、OO 0.228。used–own field gap 在 E 視窗為 0，是因為 used 等於 own；在 O 視窗才表示 donor 與 own 的差。Q 與 HHI 一起變動，只說明這次來源切換同時改變了決策影響與後期到訪集中，不能把它讀成中介比例。
