## 本輪回答

S0 上的全時段平均 Q 匹配有通過數值相容性閘門，但沒有延伸到自身閉環的 decision t=101–500。九個 LOGMAX matched 條件的 ΔQ_native 都是正的，區間都在 0 之上。最大的是 CUM LOGMAX q15，平均 0.828 [0.826, 0.830]；該條件自身閉環 late Q 約 0.957，同一窗口的 S0 late Q 約 0.129。q25 的三個 LOGMAX 記憶，自身閉環 late Q 約 0.96，S0 late Q 約 0.22。九個 ZRAW matched 的 ΔQ_native 也是正的，但只有約 0.0002 到 0.018。weight 150 的 LOGMAX 只上升約 0.0003 到 0.0004。改變最大的是高 weight 的 LOGMAX，尤其是 q15 與 q25。

q25 LOGMAX 的 18/20 連續 20 步事件在 1000/1000 個 seeds 出現，中位起始 timestep 是 4，確認後退出比例是 0。q15 LOGMAX 的事件比例是 0.989 到 0.993，中位起始是 5 或 6，有事件者的退出比例約 0.01 到 0.015。q05、全部 ZRAW、weight 150 與 S0 的這個事件都是 0/1000。CUM LOGMAX q25 在幾乎完整的樣本上，事件前兩個決策的 Q 已是 0.703（offset −2，n=996），前一個決策是 0.913（offset −1，n=1000），產生連續區間第一個 committed state 的決策是 0.947（offset 0，n=1000），確認點是 0.958（offset +19，n=1000）。offset −10 只有 n=6，offset −20 只有 n=1；圖左端的起伏不能當成 cohort 軌跡。因此 q15 與 q25 的 Q 上升和集中事件落在同一段很早的時間裡，而且 Q 在事件之後仍然維持高位。q05 LOGMAX 沒有這個事件，ΔQ_native 仍為正，而且 t=1–100 的差大於 t=401–500。

固定 S0 歷史的 late Q，CUM q25 是 LOGMAX 0.222、ZRAW 0.250，規則差約 0.028。固定該 seed 的 LOGMAX 閉環歷史時，同一組 weight 的 late Q 變成 LOGMAX 0.958、ZRAW 0.130，規則差約 0.83。固定 ZRAW 閉環歷史時則是 LOGMAX 0.651、ZRAW 0.268。HL 與 HZ 的比較同時改變位置、occupancy、base utility 與歷史記憶。

q25 LOGMAX 的 HHI 到頂之後，三種記憶終局場所相同的有 968/1000，不同的有 32/1000，tie 為 0。這個 968 與 018 單位檔一致。late visit-share 的平均 TV，RW50 對 CUM 是 0.029 [0.019, 0.040]，EXP99 對 CUM 是 0.015 [0.008, 0.023]。RW50 的事件起始平均比 CUM 晚 0.357 步 [0.219, 0.509]；EXP99 減 CUM 是 0.053 [−0.022, 0.117]。場所的邊際分布仍以 site_02 最多，約 400/1000，但 32 個 seeds 的目的地並不一致。

這些結果不足以做因果判斷。交叉評分沒有重新生成世界，規則差、歷史差與 interaction 都不是 feedback 占比或中介百分比。事件對齊是事後觀察，Q 在集中附近升高不能證明 Q 導致集中。連續 20 步也不是永久吸收態。區間條件於 018 已固定的 weights、同一套凍結架構與這 1000 個既有 seeds，不包含 weight fitting 的不確定性，也不是新的 held-out replication。
