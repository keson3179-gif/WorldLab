# WorldLab V1 Preview：範圍與驗收

狀態：`V1_PREVIEW`、`REPLAY_ONLY`、`NOT_RELEASED`。

Experiment 021：`NOT_STARTED`。

這一版是使用凍結研究資料的研究原型。頁面能開啟，不表示正式 V1 已經發布，也不表示真人行為效度已經通過。

## 目標使用者

想查看既有模擬裡，代理人如何在場所之間移動的研究者。使用者需要能對上 Experiment 020 的條件名稱，並知道畫面上的數字來自哪一份已保存結果。

## 這一版能做什麼

- 在本機瀏覽器回放 20 位代理人、5 個場所的已保存位置。
- 選擇 CUM、RW50、EXP99，LOGMAX、ZRAW，以及 q05、q15、q25。
- 選擇 seeds 1700、2199、2699。
- 左右兩個視窗分別選擇 EE、EO、OE、OO，或把其中一邊換成 S0 donor 參考回放。
- 同步播放、暫停、單步、回到起點，以及拖動時間。
- 用四個跳轉按鈕到 t＝0、t＝50、t＝51、t＝500。這些按鈕不是滑桿上的比例刻度。
- 桌面寬度下左右視窗並排；窄視窗改成上下排列。
- 目錄與三份回放都載入完成前停用回放操作。載入失敗時，頁面顯示失敗訊息與「重新載入」。
- 分開看當下人數、整段 late visit-share HHI，以及 18/20 強集中事件的起始與確認。
- 維持分析沒有合格樣本時，顯示「不適用／沒有合格樣本」。
- 從頁面連到 Research Synthesis v0.20，並在展示資料裡保留來源檔與 trajectory hash。

預設是 CUM／LOGMAX／q25，比較 EE 與 EO。參數選擇只是載入已經存在的軌跡。頁面標示「既有實驗回放」。

## 這一版尚未包含

- 新的正式模擬條件或 seeds。
- 即時 LLM 或 Ollama。
- 對話、攝影、文化、經濟或反思機制。
- 調整參數後立即重跑世界。
- 真實地圖，或沒有來源的旅客行為描述。
- 帳號、雲端服務、外部 API 與公開網站部署。
- 1000 seeds 的整體區間圖。單條回放不能代替那批結果。

## 正式 V1 還需要的驗收

- 目標使用者能在不靠開發者在旁的情況下，完成一次指定 seed 與兩條時程的比較，並正確說出 late HHI 不是滑桿當下的數字。
- 回放資料的來源、hash 與重建命令可以讓另一台已安裝同一 Python 環境的機器重現同一頁。
- 目標使用者在自己的視窗寬度下，確認左右比較、時間跳轉與載入失敗後的重試都看得懂。代理人的瀏覽器檢查不能代替這一步。
- 研究主張維持在既有綜合文件的範圍內。展示頁不新增主張。
- 真人行為效度若要納入正式 V1，必須另有真人資料與預先寫下的對照。本輪沒有這份資料。
- 發布前要有明確的版本號、已知限制與不包含項目。目前狀態保持 `NOT_RELEASED`。

## 驗證要分開看

下面三項不能互相代替。

### 自動測試

`tests/test_v1_preview.py` 會重建展示 bundle，核對 219 條軌跡與來源 hash，並用本機 Chrome 操作頁面。瀏覽器測試使用測試用的延遲、失敗與不完整回應，不改寫 `data/` 或正式 export 來製造失敗。

這一輪的行為檢查包括：載入完成前控制項停用、延遲回應時提前點選不會出錯、目錄或回放失敗時顯示錯誤且不能播放、重試成功後可以操作、重複播放不會疊出多個計時器、跳到 0／50／51／500 時左右面板與滑桿和時鐘一致、跳轉會暫停且整段 late HHI 不變、1440 與 1024 寬並排而 768 寬上下排列、切換條件後標題與軌跡和指標一起更新。

### 代理人的瀏覽器操作

代理人用 headless Chrome 對同一份頁面做了上述操作，並保存完整頁面截圖。這不是目標使用者驗收。

### 尚未進行的目標使用者驗收

目標使用者還沒有自行完成指定比較，也還沒有確認 late HHI 的讀法。正式 V1 因此仍是 `NOT_RELEASED`。

## 資料契約已經核對的項目

- 匯出 219 條軌跡，沒有重複或缺失。每條是 committed t＝0–500、20 位代理人、場所識別碼為 site_01 到 site_05。
- 匯出後再讀回，canonical trajectory hash 與 Experiment 020 保存的 hash 相同。
- q05 與尚未取得維持資格的 OE，畫面顯示「不適用／沒有合格樣本」，沒有顯示成 0%。
- 有事件的 q25 軌跡分開顯示起始與確認。沒有事件的 q05 軌跡顯示「未形成」。
- 建置前後，六個直接來源檔的 hash 不變。`v1_demo/export/manifest.json` 所列檔案吻合，且 manifest 不含自己。
- 本機服務只綁定 127.0.0.1。讀取頁面與 POST 拒絕沒有改寫來源或 manifest。

本輪沒有把「頁面能開啟」記成正式 V1 發布。
