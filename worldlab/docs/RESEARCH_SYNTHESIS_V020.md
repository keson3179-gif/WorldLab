# Research Synthesis v0.20

從選擇介面量測，到閉環社會資訊的形成與維持

這不是 Experiment 021。本輪沒有新增正式世界，沒有重新 fitting，沒有重算正式 bootstrap，也沒有呼叫 LLM 或 Ollama。Experiment 021 尚未開始。

## 摘要

WorldLab 目前是一套可重播的研究工具。它先把場所的語義效用凍結下來，再用 Python 規則推進一小群代理人的場所選擇、隨機性與佔有狀態。近期的世界實驗紀錄 `llm_calls = 0`。代理人沒有在每一步重新對話或推理。世界執行的次數只說明計算已經完成，不說明結果有效，也不說明它像真人觀光。

到目前為止，證據分成三條，不能併成同一個「持續」指標。

第一條是量測。直接二選一介面裡，同一物理選項被標成 A 或 B，pooled 選擇率差是 0.6025（n＝4800）。後來的因子設計把標籤、位置與列舉順序拆開：A 標籤優勢是 0.5611111111111111（pooled n＝2880），第一位置差是 −0.08611111111111108，enum 順序差是 0。這兩個數字來自不同對照，不能互換名稱。

第二條是有限時域的歷史差異。比較的是兩條配對歷史的佔有率距離，不是單一世界有多集中。在 seeds 100–199、H2000、已測的 λ 網格上，onset band 是 (0.40, 0.60]，整體分類是 `FULL_ONSET_REPLICATION`。這個區間的內部沒有被測過。RW50、λ＝.60 的平均約 0.025925，95% 區間跨過 0.025。點估計分類可以重現，邊界還沒有被精確定位。2000 steps 是指定時域，新 seeds 是新的隨機經歷。

第三條是記憶、轉換、校準與閉環集中。相同的 social weight 可以對應很不相同的決策影響。在參考歷史上把平均 Q 校準到同一目標帶，閉環之後的集中程度仍然可以分開。把 social field 的來源與 t＝51 的時程換掉，會改變集中何時形成、以及已經形成的集中能否維持。Q 描述的是條件選擇機率分布改變多少，不是實際換了多少目的地。HHI 描述單一世界的 visit share 有多集中。HHI＝1 只表示該世界的累積出現集中在一個場所；不同 seed 的那個場所可以不同。

最有把握、而且來源能對上的主張有四項：任意標籤會改變直接選擇介面的測量結果；在指定架構下，早期介入可以留下有限時域的歷史差異；參考歷史上的平均 Q 匹配，不足以保證閉環集體行為相近；在指定 weights、seeds 與時程下，替換 social-field 來源會改變集中的形成與維持。每項的樣本、視窗與不能推出的結論記在 `docs/research_synthesis_v020/evidence_index.json`。

目前回答不了的事情同樣清楚：20 個代理人、5 個場所、同一份 frozen Atlas；技術校準沒有對上真人行為；重現性沒有提供外部效度；018–020 的區間條件於已固定 weights；區間是 pointwise；020 是指定來源替換政策的效果。後文列出最多三個可討論的後續問題。它們還沒有被授權執行。

## 固定用語

- **seed**：一條隨機經歷的編號。換 seed 是換隨機過程，不是換一套新的人口樣本。
- **Q**：社會資訊使條件選擇機率分布改變的程度。它不是實際更換目的地的比例。
- **HHI**：一個世界裡，場所 visit share 的集中程度。017–020 的 late HHI 使用 committed t＝101–500 的累積 presence。它不是逐步 occupancy HHI 的平均。
- **occupancy TV**：兩條配對歷史的佔有率分布距離。它和單一世界的 HHI 是兩種量。
- **λ**：把共享場與自身內生場混合起來的控制參數。它是模擬裡的操作，不是已定位的臨界點。
- **q05／q15／q25**：018 在參考歷史上為平均 Q 設定的校準標籤。它們不保證後來的 recipient 實際達到同一個 Q。
- **E**：recipient 自身記憶產生的 social field。
- **O**：同一個 seed 上，S0 donor 產生的 social field。020 的 O 只替換 social field。recipient 的位置、occupancy 與 base utility 仍由自身世界更新。自身 shadow memory 在使用 O 時繼續更新，不會被清空。
- **四條路徑**：EE 全程 E；EO 在決策 1–50 使用 E、51–500 使用 O；OE 前段 O、後段 E；OO 全程 O。切換點是決策 t＝51。

019 與 020 的 Q 視窗各自標在來源上。018 的全時段參考 Q 不拿來和 019 的 late window 相減。

## A. 選擇介面與量測偏誤

早期直接選擇把兩個選項同時放在一個畫面裡。001c 的對照是同一物理選項標成 A 與標成 B：pooled 選擇率差 `difference_A_minus_B` 是 0.6025，n＝4800。這是 **A/B 呈現差**。

001d 把因素拆開。A 標籤優勢是 0.5611111111111111，pooled n＝2880。第一位置優勢是 −0.08611111111111108。enum 順序優勢是 0。這是 **A-label effect**、**position effect** 與列舉順序，和 001c 的 0.6025 不是同一個對照。

固定設定下的重複性，是同一套規則與同一批凍結輸入能否再跑出已記錄的結果。它回答程式與隨機過程是否可重播。它不回答真人是否會做出同樣的場所選擇。真人行為效度需要真人資料，這份綜合沒有那份資料。

後續架構改為 independent single-place utility evaluation：場所效用先被估出並凍結，世界裡的選擇不再靠畫面上的 A/B 標籤。LLM 在那個階段提供固定的語義效用評估。效用凍結之後，Python 負責選擇、隨機性、狀態轉移與世界動態。017–020 的正式世界沿用這份 frozen Atlas，紀錄的 LLM 呼叫是 0。

這一條的證據性質是量測。主張 M01、M02 的來源路徑寫在 evidence index。001–016 其餘軌跡的細節透過既有的 v0.16 索引間接引用；本輪沒有重讀那些軌跡，也沒有把它們重新驗證一遍。

## B. 早期介入與有限時域歷史差異

007–016 的核心比較是配對歷史。一條歷史接受早期介入，另一條使用 matched-RNG 的對照，讓可對上的隨機數對齊。結果是兩條歷史的 occupancy TV，以及這個距離在指定 horizon 上的平均、個別 seed 是否跨過門檻、以及哪些 seed 持續。群體平均、個別持續比例與 seed identity 是三個不同的摘要。

正式判定使用事先固定的規則。016 的 H2000 已測 λ 只有 0.40、0.60、0.80、1.00。整體 onset 標籤是 `FULL_ONSET_REPLICATION`，已測 band 是 (0.40, 0.60]。(0.40, 0.60) 的內部沒有觀測點，圖 2 只畫已測的點，沒有把未測位置連成曲線。

H2000、seeds 100–199、n＝100 的平均 occupancy TV：

| 架構 | λ＝0.40 | λ＝0.60 | λ＝0.80 | λ＝1.00 |
| --- | ---: | ---: | ---: | ---: |
| RW50 | 0.002005 | 0.025924999999999997 | 0.06154 | 0.092915 |
| EXP99 | 0.01491 | 0.041675 | 0.061059999999999996 | 0.08216 |

RW50、λ＝.60 的 95% 區間是 [0.018565, 0.033174999999999996]，跨過 0.025。該格的點估計分類是 persistent residual，seed 持續比例是 0.34。EXP99、λ＝.40 的平均是 0.01491，分類是 attenuated；EXP99、λ＝.60 的平均是 0.041675，分類是 persistent residual。點估計分類在新 seeds 上重現，並沒有把 onset 邊界定位到區間內部的某一個 λ。

2000 steps 是這個實驗的時域。它是一段有限歷史的距離。新 seeds 100–199 是同一架構下的另一批隨機經歷，不是新人口，也不是外部效度驗證。

這一條的證據性質是重現。主張 H01、H02 直接核對 `experiment_016_summary.json`。更早的校準與 007–015 的譜系留在 v0.16 綜合與其 evidence index，本輪標成間接引用。

## C. 記憶、轉換、校準與閉環集中

### 017：相同 weight，不同決策影響

017 cohort B 把 memory 與 transformation 拆開，social weight 固定在 150，n＝500。全時段平均 Q：CUM LOGMAX 是 0.004824789171135996，CUM ZRAW 是 0.27403079610316294。同一 weight 下，轉換方式改變了條件選擇分布。late visit-share HHI（committed t＝101–500）則是另一個量：CUM LOGMAX 約 0.2017085099375，CUM ZRAW 約 0.2504308993125，S0 約 0.201512709625。Q 的差距不能改寫成 HHI 的差距。

### 018：平均 Q 匹配，閉環 HHI 仍可分開

018 在 S0 參考歷史上校準平均 Q，再看 seeds 700–1699 的 held-out 轉移。18 個 matched 條件的全時段參考 Q，其區間都落在各自的目標帶內。例如 CUM LOGMAX q25 的平均 Q 是 0.25003276461966745，區間在 [0.245, 0.255] 內；同一條件的 late HHI 是 1.0，區間是 [1, 1]。CUM LOGMAX q05 的平均 Q 約 0.05026911230494481，late HHI 約 0.26754459415625004。q05、q15、q25 是參考校準標籤。平均 Q 匹配不保證時間分布、agent 分布、機率向量或閉環 HHI 匹配。

[1, 1] 這類退化區間表示這個 cohort 裡觀察到的值相同。它沒有保證未見 seeds 的母體結果必然相同。

### 019：同一窗口的交叉評分

019 使用同一批 seeds 700–1699 的既有軌跡，在 decision t＝101–500 比較 native 歷史與 S0 歷史上的 Q。CUM LOGMAX q25 的 native Q 是 0.9576049000760911，同一規則放在 S0 歷史上是 0.22216047158473207。這是固定狀態下換評分規則，與更換整條歷史，兩件事都留在離線評分裡。它不是 020 那種直接改寫進行中世界的干預。018 的全時段參考 Q 與這個 late window 不是同一個基準，兩者不相減。

事件對齊與 Q 上升描述的是時間上一起出現的量。它們單獨不能證明因果方向。q25 LOGMAX 的場所計數是 same 968、different 32、tie 0。集中程度相同時，終點場所仍可以不同。這個計數屬於 019 的 cohort，不與 020 的終點計數合併。

### 020：來源與時程的干預

020 在 seeds 1700–2699、n＝1000、18 個已固定 weights 上，直接替換 social-field 來源，並在決策 t＝51 切換。數值回到凍結的 uncertainty 與更正後的稽核。更正事項如下。

1. 六個合格的 EO LOGMAX 條件都在 t＝51–52 解除集中。中位數是 51。CUM q15 是 979 個合格，其中 t＝51 有 978、t＝52 有 1；EXP99 q15 是 942、941、1；RW50 q15 是 782、781、1；CUM q25 是 1000、999、1；EXP99 q25 是 1000、999、1；RW50 q25 是 998、997、1。`original_exit` 與 `release_time` 一致。維持數是 0，解除數等於合格數，轉移數是 0。
2. 18 個 EO−OO 區間裡，17 個包含 0。EXP99／ZRAW／q25 的區間高於 0，平均差是 1.3206593749999967e-05，區間是 [2.0166250000004103e-06, 2.4608343750000926e-05]。沒有事先定義等價準則。這個幅度很小，同時它的區間位於 0 的上方。
3. `field_gap_*` 是 used–own field gap，也就是所用場與 recipient 自身場之差的平均絕對值。E 路徑上這個差為 0，是因為 used 被設成 own。它不表示 donor 與 own 相同。
4. 原始 manifest 列出 2020 個檔案，其中 2019 個與當時紀錄吻合。`manifest_all_matched` 是 false。唯一的例外是 `progress.jsonl`：manifest 紀錄的是完成宣告之前的內容，檔案末尾多出的一筆是之後追加的 finished 紀錄。原始檔與 manifest 都保留。本輪引用這份稽核，沒有重新掃描全部歷史軌跡。
5. [0, 0] 與 [1, 1] 的 bootstrap 退化區間，描述的是已觀察 cohort。它們不能保證未見 seeds 的母體結果必然相同。
6. 維持分析只在切換前合格的 seed 中進行。O-early 的合格數是 0 時，維持率是 NA。圖 4 不把 NA 畫成 0。早期形成比例為 0 是另一個量：它有合格分母以外的事件定義，和維持率的 NA 分開。
7. 到 t＝500 都沒有跌破門檻，只表示在這個時域內沒有觀察到退出。

高權重 LOGMAX 的 E-early 形成比例：q15 為 CUM 0.98（合格 979）、EXP99 0.942（942）、RW50 0.786（782）；q25 為 CUM 1.0（1000）、EXP99 1.0（1000）、RW50 0.998（998）。這些條件的 O-early 早期形成比例是 0，合格數是 0，維持率是 NA。OE 的 q25 LOGMAX 雖然早期形成是 0，後段改回 E 之後仍出現較晚的新事件：CUM 的 `late_new` 是 984，RW50 是 1000，EXP99 是 999。q05 與全部 ZRAW 沒有進入上述合格 EO 集合；它們的 late HHI 與早期形成留在圖 4 的六個分面和 `paths_020.csv`，沒有被省略。

CUM LOGMAX q25 的 late HHI：EE 是 1.0，EO 約 0.23338617443749998，OE 約 0.97471054434375，OO 約 0.23339081268749998。EE 的終點場所計數是 site_02 392、site_01 302、site_04 133、site_05 110、site_03 63。HHI＝1 表示每一個世界內部的累積 presence 集中於一處；這 1000 個世界的那一處並不相同。

020 的證據性質是干預。它估計的是指定來源替換政策的效果。它沒有把 Q 配成相等之後再分離 feedback，也沒有給出機制占比。

## 目前證據以及未來研究問題

- 設定是 20 個代理人、5 個場所、同一份 frozen Atlas。
- 技術校準對的是模擬裡的 Q 目標帶。它沒有校準真人選擇。
- 同一架構在新 seeds 上重現，提供的是隨機重現。外部效度需要架構之外的資料。
- 018–020 的區間條件於已經固定的 weights。重新 fitting 的不確定性不在這些區間裡。
- 區間是 pointwise。它們沒有經過多重比較之後的整體保證。
- B 的配對歷史距離與 C 的單一世界集中程度回答不同問題。把它們加成一個 persistence 會混掉比較單位。
- 020 的政策效果留在指定的來源、weights、seeds 與時程裡。

## 觀光研究連結

模型裡已經操作的是：凍結的場所效用、離散場所選擇、由歷史構成的社會資訊，以及 visit share 的集中。這些操作可以對應到可研究的問題，例如景點熱度資訊怎樣呈現、早期曝光與後來持續出現的社會資訊是否作用不同、以及相同的集中程度是否對應不同的目的地。

下列概念還沒有在這個模型裡被直接建模或驗證：真實旅遊動機、文化意義、凝視、攝影、敘事傳播、地方認同與真人行為。現有的 Q、HHI 與 occupancy TV 不能用來證明這些理論。它們只標出，若要談那些理論，還缺哪一類證據。

## 可討論的後續方向

這三項只標出未決問題與需要的新證據。本輪不實作，也不建立 Experiment 021。

1. **相同集中是否對應相同目的地。** 未決問題是：late HHI 相同時，終點場所的身份如何分布。020 的 CUM LOGMAX q25 EE 已經顯示 HHI＝1 同時終點分在五個 site。需要的新證據是事前定義的場所身份摘要，以及它與集中指標分開報告的不確定性。現有終點計數只描述已跑過的 seeds。
2. **來源時程的效果裡，有多少來自 Q 的差異。** 未決問題是：若 recipient 的決策影響被配到與 donor 相近，t＝51 的切換是否仍改變形成與維持。020 替換的是整份 social field，Q 沒有被配平。需要的新證據是一個把 Q 對齊之後再切換來源的設計；在那之前，不能把 020 讀成純 feedback 的占比。
3. **熱度資訊的呈現是否本身改變集中。** 未決問題是：把佔有或熱度顯示給選擇者時，介面標籤與位置會不會再次進入測量。001c 與 001d 顯示直接選擇介面有標籤與位置差，現行世界則使用凍結效用，裡面沒有一層可開關的熱度呈現。需要的新證據是一組把呈現方式獨立出來的測量，以及它與閉環集中分開的對照。

排序的理由：第 1 項已經有凍結終點計數，缺的是正式的身份摘要。第 2 項決定 020 能被解釋到哪一層機制。第 3 項才把介面量測接回觀光資訊的呈現，而且需要新的測量層。
